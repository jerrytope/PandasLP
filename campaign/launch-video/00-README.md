## Production pipeline (Higgsfield)

1. **Characters first.** Generate the OBI character stills in Higgsfield Soul using the
   character sheet in file 01 — reuse the description *verbatim* in every prompt for consistency.
2. **Stills → motion.** For each scene in file 03, generate the start frame, pick the best,
   then run image-to-video with the listed motion prompt and camera preset.
3. **UI scenes are screen recordings, not AI.** Scenes 4–5 (the chat interview and PDF)
   should be captured from the real app at pandaslp.com.ng — it's free credibility and always
   crisper than generated UI. Record at 2x scale, dark theme.
4. **Assemble** in CapCut / Premiere: master film first, then cutdowns (file 04) reuse the
   same clips — no extra generation needed.
5. **Voiceover:** warm Nigerian male or female VO, measured pace (~140 wpm), recorded or
   ElevenLabs. Music: minimal piano + low strings, swelling at the turn (0:14), never louder
   than the VO.
